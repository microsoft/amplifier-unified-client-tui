# Converge practice

Read [VISION](../docs/VISION.md), [contracts](../contracts/composition.v1.md) and
[PLAN](PLAN.md) before implementation. A changed requirement amends desired direction
before work is derived from it. Each parallel owner has a public seam, focused
verification and a concrete package handoff; integrations use independently installed
packages, not sibling source imports. User-authorized implementation does not ratify
DRAFT contracts. Structural checks do not establish behavioral conformance.

The historical method provenance in [method-source.json](method-source.json) records
the source used to establish these document shapes. That private archive is not
included or asserted to be the latest upstream method. Current project coordination
may adopt newer public method revisions explicitly without rewriting this receipt.

Keep implementation observations in [ACCEPTANCE](ACCEPTANCE.md). Preserve unknown
outcomes and source evidence. Do not turn a partial or blocked verification into a
completion claim. Scope tests to owned temporary state and independent public peers.
