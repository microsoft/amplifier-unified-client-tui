# Native renderer verification

Ratatui is the selected product frontend. Preserve actual terminal transcript, copy,
keyboard, resize, accessible colour-free states and editor revision/CAS behavior.
Use 40-column narrow, 120-column typical and larger diagnostic windows; label static
presentation scenes versus AHP-backed execution. Capture tools reconstruct font/cell
state and disclose that boundary. Alternative frontends must satisfy these obligations
through the public presentation seam and provide independently measured evidence.
